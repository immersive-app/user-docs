# Coach

Le coach répond aux questions sur ce que vous étudiez. Ouvrez-le depuis l'élément sur lequel vous avez une question, et il démarre avec cet élément sous les yeux : une carte de révision, une note de grammaire, un verbe, un mot, un texte ou une correction.

## Poser une question

Les pages qui ont la barre de navigation ont un bouton du coach en bas de l'écran ; le lecteur et les sessions de révision ont le leur. Le libellé dit ce que le coach verra :

- **Demander au coach** : une question générale, depuis n'importe quelle page (et depuis le haut de votre Profil).
- **Demander à propos de cette carte** : en révision, une fois la réponse affichée.
- **Demander à propos de cette note**, ou **Demander à propos de cet exercice** sur un exercice : sur une note de grammaire. Sélectionner un passage d'une note propose de poser une question sur ce seul passage.
- **Demander à propos de ce verbe** : sur une page de verbe ou une page de forme.
- **Demander à propos de cette comparaison** : sur une comparaison de la grammaire de la lecture.
- **Demander à propos de ce texte** : dans le lecteur (aussi dans les réglages de lecture), et sur une page de correction.
- **Poser une question** : dans le panneau **Plus** d'un mot ou d'une phrase, dans le lecteur.
- **Demander à propos de cette correction** : sur chaque correction de votre écrit.

Tapez votre question et appuyez sur Entrée (Maj+Entrée passe à la ligne). La réponse apparaît à mesure qu'elle s'écrit. Sur un ordinateur, un chat vide propose quelques **Suggestions** de questions, comme « Décompose cette phrase » dans le lecteur ou « Compare avec une langue que je connais » sur une note de grammaire ; **Agrandir** et **Réduire** changent la taille du panneau.

## Comment le coach répond

- Dans votre langue d'affichage, sauf si vous lui écrivez dans la langue que vous apprenez.
- Brièvement, et à propos de la langue : il signale quand une langue que vous connaissez fonctionne de la même façon, et il décline les questions qui n'ont rien à voir avec l'apprentissage des langues.
- Chaque fois que vous ouvrez le coach, il commence un nouveau chat.

Si vous envoyez beaucoup de messages d'affilée, le coach vous demande de patienter une minute (« Trop de messages d'affilée »). S'il ne peut pas répondre, votre message est conservé et **Réessayer** le renvoie.

## Vos chats

**Profil → Coach** liste vos chats, les plus récents d'abord, chacun avec ce sur quoi il portait (Carte, Note, Verbe, Texte...), sa première ligne et sa date. Touchez-en un pour le relire ; son libellé renvoie à ce sur quoi il portait. Si cet élément a été supprimé depuis, le chat garde ce qu'il a vu.

Le bouton corbeille supprime un chat, après une confirmation : le coach ne s'en souviendra pas.

Vos chats sont privés : les professeurs à qui vous donnez accès ne peuvent pas les voir.

## Le bouton Coach de l'éditeur

Quand vous écrivez, **Coach** dans la barre d'outils de l'éditeur est différent : il donne une relecture ponctuelle de votre texte enregistré, pas un chat. Voir [Écrire des documents](documents/writing-documents.md#la-relecture-du-coach).
