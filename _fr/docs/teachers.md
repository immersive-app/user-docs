# Professeurs

Si vous étudiez avec un professeur, vous pouvez le laisser suivre vos progrès, à vos conditions : vous choisissez ce qu'il voit et pour combien de temps, et vous pouvez y mettre fin à tout moment. Il voit ces parties de votre profil en lecture seule, et jamais les détails de votre compte.

## Donner accès à un professeur

1. Ouvrez **Profil → Professeurs** et choisissez **Créer un code d'accès**.
2. Choisissez ce que le code déverrouille : **Progression** (niveaux et bilans par domaine), **Activité** (heatmap, effort et journal d'étude) et **Vocabulaire** (mots collectés et leurs comptes). Progression et Activité sont cochés au départ.
3. Choisissez quand l'accès **Expire** : **Fin du trimestre** (31 août), **Dans un mois**, **Dans une semaine** ou **Sans expiration**.
4. Choisissez **Créer le code** et remettez le code à votre professeur, ou utilisez **Copier le lien** pour lui envoyer un lien avec le code déjà rempli.

Un code que personne ne réclame expire après sept jours. Tant qu'il n'est pas réclamé, il est listé sous **Codes d'accès**, avec **Annuler**.

## Mettre fin à l'accès

Les professeurs qui ont réclamé un code sont listés avec ce qu'ils peuvent voir et depuis quand. **Révoquer** met fin immédiatement à l'accès d'un professeur.

## Pour les professeurs

Pour suivre un élève, vous avez besoin de votre propre compte Immersive :

1. Connectez-vous, puis ouvrez le lien que votre élève vous a envoyé, ou allez sur **Réclamer un code d'accès** (`/teach/claim`) et tapez le code.
2. Choisissez **Réclamer le code**.

Vous voyez alors les parties du profil de votre élève qu'il a choisies, sous un bandeau qui indique de qui est le profil, qu'il est en lecture seule, et quand l'accès expire :

- **Progression** : où il en est, et ses paquets, ses documents et ses écrits.
- **Activité** : son effort, ses jours d'étude et son journal d'étude.
- **Vocabulaire** : les mots et les phrases qu'il a collectés, avec un filtre par type.

Immersive n'a pas d'entrée de menu pour les élèves que vous suivez, alors ajoutez la page à vos favoris pour y revenir. Si un code n'est pas accepté, la page dit pourquoi : il ne correspond à rien, c'est le vôtre, ou il n'est plus valide (demandez-en un nouveau à votre élève).
