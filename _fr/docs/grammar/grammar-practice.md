# Pratique de grammaire

Lire une note une fois ne suffit pas à fixer un point de grammaire. **S'entraîner** transforme les exercices d'une note en cartes de révision qui reviennent selon le même calendrier fondé sur la mémoire que vos paquets.

## S'entraîner sur une note

Sur une note de grammaire, **S'entraîner** (avec le nombre de cartes à revoir, nouvelles ou en attente) crée les cartes de la note, si vous n'en avez pas encore, et lance une révision de cette note. Les cartes vont dans un paquet appelé **Pratique de grammaire** pour la langue, que vous voyez aussi dans Mes paquets.

## Réviser la grammaire

Les révisions de grammaire peuvent porter sur une note, un domaine, un niveau ou tout :

- Sur la page Grammaire : **Réviser 3 cartes**, ou **S'entraîner · 5 nouvelles** quand rien n'est à revoir.
- Sur la page d'un niveau : **Réviser 3 cartes au niveau B1**.
- Sur la page d'un domaine : **Réviser ce domaine** ou **S'entraîner sur ce domaine**.
- Sur une note : **S'entraîner**.

La révision fonctionne comme celle d'un paquet (voir [Réviser les cartes](../decks/reviewing-cards.md)), avec trois modes :

- **Lire** : lisez la carte, rappelez-vous la réponse et notez-vous (**Notez pour continuer**).
- **Écrire** : tapez la réponse ; Immersive la vérifie et propose une note.
- **Choisir** : choisissez la bonne forme parmi les options (les touches numériques fonctionnent aussi) ; choisir envoie la réponse et note la carte.

Immersive se souvient du mode utilisé pour la grammaire séparément de vos révisions de paquets. Une carte à laquelle on ne peut pas répondre dans le mode choisi s'affiche dans le mode le plus proche qui convient.

## Quand rien n'est à réviser

Sans carte de grammaire, la page de révision affiche **Pas encore de cartes** et suggère des notes à essayer. Quand des cartes existent mais qu'aucune n'est à revoir, elle dit quand la prochaine arrive. Dans les deux cas, elle propose les notes recommandées, **Parcourir** votre niveau, et **Retour à la grammaire**.

## Où vous en êtes

Chaque révision met à jour votre maîtrise de la note, de son domaine et de son niveau, affichée sur la page Grammaire et sur chaque note. Les cartes de grammaire à revoir apparaissent aussi sous **À suivre** dans [Profil → Progression](../profile.md#progression).
