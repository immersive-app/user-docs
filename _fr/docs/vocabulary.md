# Vocabulaire

Votre Vocabulaire est la liste des mots et des phrases que vous avez réellement rencontrés pendant vos études. Vous n'y tapez jamais rien — il se collecte tout seul pendant que vous utilisez Immersive — et il vit dans votre Profil, sous l'onglet **Vocabulaire**.

---

## Comment le vocabulaire se collecte

Trois activités alimentent automatiquement votre Vocabulaire :

- **Les mots et les phrases que vous traduisez dans le lecteur.** Touchez un mot ou une phrase dans un document pour voir sa traduction, et l'élément est enregistré.
- **Les phrases manquées en révision.** Quand une révision se passe mal, l'élément atterrit ici pour que vous décidiez quoi en faire.
- **Les corrections de vos écrits.** Les mots qui reviennent corrigés dans vos documents écrits sont collectés aussi.

Chaque entrée retient combien de fois vous l'avez **vue**, **manquée** et **révisée**, si bien que la liste sert aussi de registre des mots qui vous posent problème.

## Parcourir votre liste

Ouvrez **Profil → Vocabulaire**. En haut, vous voyez vos totaux — combien d'éléments vous avez collectés et combien vous avez enregistrés. Vous pouvez :

- **Chercher** vos mots avec le champ de recherche.
- **Filtrer par type** — tous les types, mots seulement ou phrases seulement.
- Cocher **Enregistrés seulement** pour ne voir que les éléments marqués comme méritant d'être gardés.

## Enregistrer et écarter

Tout ce que vous traduisez ne mérite pas d'être étudié. Sélectionnez les entrées qui comptent pour vous, puis :

- **Enregistrer** les garde marquées : elles ressortent et peuvent être filtrées avec Enregistrés seulement.
- **Écarter** efface les entrées que vous ne voulez pas suivre.

## Transformer le vocabulaire en paquet

Tout l'intérêt de collecter du vocabulaire est de le réviser. Pour créer un paquet depuis votre liste :

1. Ouvrez **Profil → Vocabulaire**.
2. Sélectionnez les mots et les phrases que vous voulez étudier.
3. Choisissez **Créer un paquet à partir de la sélection**.

Immersive crée un nouveau paquet (nommé « Vocabulaire » avec la date du jour) avec une carte par élément sélectionné, prêt à réviser comme n'importe quel autre paquet. Voir [Réviser les cartes](decks/reviewing-cards.md).

## Si votre liste est vide

Le Vocabulaire ne se remplit qu'en étudiant. Le moyen le plus rapide de le lancer est d'ouvrir un document et de lire : chaque mot que vous traduisez apparaît ici. Voir [Lire des documents](documents/reading-documents.md).
