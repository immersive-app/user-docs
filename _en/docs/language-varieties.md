# Language varieties

Several of Immersive's languages are spoken in more than one country, with different words and spellings. Immersive's interface is written in one variety of each language, the one used in Europe:

| Language | Variety | For example |
|---|---|---|
| English | British | colour, organise, mobile |
| French | France | no Canadian (Québec) forms |
| Spanish | Spain | *móvil*, *ordenador*, not *celular*, *computadora* |
| Portuguese | European (Portugal) | *ecrã*, *telemóvel*, *o meu*, not *tela*, *celular*, *meu* |
| Italian | Italy | |
| Catalan | Catalonia | |

## What it covers

- The app's interface: every screen, button and message.
- The emails Immersive sends you.
- This user guide, in all six of its languages.

## What it does not cover

The variety is about how Immersive talks to you, not about the language you are learning.

- **Grammar notes** in Portuguese, and their translations into Portuguese, are written in European Portuguese.
- **Other content** does not follow one variety. Example sentences come from many speakers, and the coach's replies are written fresh each time, so either can use a word or spelling from another country. Both are still correct for that country.

## Changing the interface language

Open **Profile → Account → Languages** and choose your **Display language**. See [Profile & Progress](profile.md#account).

## A word looks wrong

If a word in the interface belongs to another variety, it is a mistake, like a missing translation. Tell us through the **Contact** link in the footer of Immersive's public pages. For a mistake in a grammar note, use **Something wrong here?** on that note.
