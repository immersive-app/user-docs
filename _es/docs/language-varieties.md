# Variedades de idioma

Varios idiomas de Immersive se hablan en más de un país, con palabras y grafías distintas. La interfaz de Immersive está escrita en una sola variedad de cada idioma, la que se usa en Europa:

| Idioma | Variedad | Por ejemplo |
|---|---|---|
| Inglés | Británico | *colour*, *organise*, *mobile* |
| Francés | Francia | ninguna forma canadiense (de Quebec) |
| Español | España | *móvil*, *ordenador*, no *celular*, *computadora* |
| Portugués | Europeo (Portugal) | *ecrã*, *telemóvel*, *o meu*, no *tela*, *celular*, *meu* |
| Italiano | Italia | |
| Catalán | Cataluña | |

## Qué incluye

- La interfaz de la aplicación: cada pantalla, botón y mensaje.
- Los correos que te envía Immersive.
- Esta guía de uso, en sus seis idiomas.

## Qué no incluye

La variedad tiene que ver con cómo te habla Immersive, no con el idioma que aprendes.

- **Las notas de gramática** en portugués, y sus traducciones al portugués, están escritas en portugués europeo.
- **El resto del contenido** no sigue una sola variedad. Las frases de ejemplo vienen de muchos hablantes, y las respuestas del coach se escriben de nuevo cada vez, así que ambas pueden usar una palabra o una grafía de otro país. Siguen siendo correctas para ese país.

## Cambiar el idioma de la interfaz

Abre **Perfil → Cuenta → Idiomas** y elige tu **Idioma de visualización**. Ver [Perfil y progreso](profile.md#cuenta).

## Una palabra parece incorrecta

Si una palabra de la interfaz es de otra variedad, es un error, como una traducción que falta. Avísanos con el enlace **Contactar** en el pie de las páginas públicas de Immersive. Para un error en una nota de gramática, usa **¿Algo no cuadra?** en esa nota.
