# Variedades de língua

Várias línguas do Immersive falam-se em mais de um país, com palavras e grafias diferentes. A interface do Immersive está escrita numa só variedade de cada língua, a que se usa na Europa:

| Língua | Variedade | Por exemplo |
|---|---|---|
| Inglês | Britânico | *colour*, *organise*, *mobile* |
| Francês | França | nenhuma forma canadiana (do Quebeque) |
| Espanhol | Espanha | *móvil*, *ordenador*, e não *celular*, *computadora* |
| Português | Europeu (Portugal) | *ecrã*, *telemóvel*, *o meu*, e não *tela*, *celular*, *meu* |
| Italiano | Itália | |
| Catalão | Catalunha | |

## O que abrange

- A interface da aplicação: cada ecrã, botão e mensagem.
- Os e-mails que o Immersive lhe envia.
- Este guia do utilizador, nas suas seis línguas.

## O que não abrange

A variedade diz respeito à forma como o Immersive fala consigo, não à língua que está a aprender.

- **As notas de gramática** em português, e as suas traduções para português, estão escritas em português europeu.
- **O resto do conteúdo** não segue uma só variedade. As frases de exemplo vêm de muitos falantes, e as respostas do coach são escritas de novo de cada vez, por isso ambas podem usar uma palavra ou uma grafia de outro país. Continuam corretas para esse país.

## Mudar o idioma da interface

Abra **Perfil → Conta → Idiomas** e escolha o seu **Idioma de exibição**. Ver [Perfil e Progresso](profile.md#conta).

## Uma palavra parece errada

Se uma palavra da interface pertence a outra variedade, é um erro, como uma tradução em falta. Avise-nos através da ligação **Contactar** no rodapé das páginas públicas do Immersive. Para um erro numa nota de gramática, use **Algo errado aqui?** nessa nota.
