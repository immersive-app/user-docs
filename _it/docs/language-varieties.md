# Varietà linguistiche

Diverse lingue di Immersive si parlano in più di un paese, con parole e grafie diverse. L'interfaccia di Immersive è scritta in una sola varietà di ogni lingua, quella usata in Europa:

| Lingua | Varietà | Per esempio |
|---|---|---|
| Inglese | Britannico | *colour*, *organise*, *mobile* |
| Francese | Francia | nessuna forma canadese (del Québec) |
| Spagnolo | Spagna | *móvil*, *ordenador*, non *celular*, *computadora* |
| Portoghese | Europeo (Portogallo) | *ecrã*, *telemóvel*, *o meu*, non *tela*, *celular*, *meu* |
| Italiano | Italia | |
| Catalano | Catalogna | |

## Cosa comprende

- L'interfaccia dell'app: ogni schermata, pulsante e messaggio.
- Le email che Immersive ti invia.
- Questa guida utente, in tutte e sei le sue lingue.

## Cosa non comprende

La varietà riguarda il modo in cui Immersive ti parla, non la lingua che stai imparando.

- **Le note grammaticali** in portoghese, e le loro traduzioni in portoghese, sono scritte in portoghese europeo.
- **Il resto dei contenuti** non segue una sola varietà. Le frasi di esempio vengono da molti parlanti, e le risposte del coach sono scritte ogni volta da capo, quindi entrambe possono usare una parola o una grafia di un altro paese. Restano corrette per quel paese.

## Cambiare la lingua dell'interfaccia

Apri **Profilo → Account → Lingue** e scegli la tua **Lingua di visualizzazione**. Vedi [Profilo e progressi](profile.md#account).

## Una parola sembra sbagliata

Se una parola dell'interfaccia appartiene a un'altra varietà, è un errore, come una traduzione mancante. Segnalacelo con il link **Contatto** nel piè di pagina delle pagine pubbliche di Immersive. Per un errore in una nota grammaticale, usa **Qualcosa non torna?** su quella nota.
